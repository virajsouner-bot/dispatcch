# dispatcch

### Modern Logistics & Fleet Management Web Application

Dispatcch is a modern logistics management web application designed to simplify and organize logistics operations such as shipments, orders, vehicles, drivers, and delivery services.

The application provides a centralized dashboard where logistics teams can monitor and manage their operations through a clean and intuitive interface.

---

## ✨ Features

### 📊 Dashboard
- Overview of logistics operations
- Shipment statistics
- Order tracking
- Fleet overview
- Driver information
- Service information
- Modern logistics control-center interface

### 📦 Shipments
- View shipments
- Search shipments
- Filter shipments by status
- Add new shipments
- Delete shipments
- Track shipment information

### 🛒 Orders
- Manage customer orders
- Search and filter orders
- Add new orders
- View order details
- Delete orders
- Monitor order status

### 🚛 Vehicle Management
- Add vehicles
- View vehicle details
- Assign drivers
- Manage vehicle types
- Delete vehicles

### 👨‍✈️ Driver Management
- Add drivers
- Store driver contact information
- Store license details
- Assign vehicles
- Manage driver records

### 🛠️ Services
- Create logistics services
- Add service descriptions
- Set service prices
- Configure delivery options
- Manage supported vehicles

### 👤 Profile
- Manage user information
- Update company information
- Edit contact details
- Save profile information

### 🔐 Login
- Login interface
- Email and password fields
- Basic frontend authentication flow
- Login state management
